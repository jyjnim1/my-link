# 마이링크 (MyLink) 사용자 시나리오

서비스의 두 가지 주요 핵심 주체(방문자와 소유자)를 기준으로 발생 가능한 모든 행동 과정을 `사용자는 __하기 위해 __한다.` 형식으로 정의한 시나리오입니다.

---

## 1. 방문자: 마이링크 페이지 방문 과정

- **페이지 접근**
  - 사용자는 소유자가 공유하고 싶은 여러 외부 링크를 한 페이지 내에서 확인**하기 위해** 전달받은 퍼블릭 URL(`/디스플레이네임`)로 접속**한다**.
- **정보 확인**
  - 사용자는 본인이 생각한 그 사람의 링크가 맞는지 판단**하기 위해** 화면 최상단에 노출된 디스플레이 네임(실제 이름)과 바이오(소개글)를 확인**한다**.
  - 사용자는 클릭하기 전 어떤 플랫폼으로 이동할지 예측**하기 위해** 화면에 나열된 각 링크 버튼 내부의 파비콘(Favicon) 이미지와 텍스트 제목을 읽어본**다**.
- **목표 행동 (클릭)**
  - 사용자는 관심이 생긴 소유자의 외부 사이트 혹은 콘텐츠로 완전히 이동**하기 위해** 리스트에 나열된 특정 링크 버튼 중 하나를 클릭**한다**. 
  - *(※ 관리자 기능 연동)* 사용자가 위와 같이 원하는 정보를 얻**기 위해** 특정 버튼을 클릭하면, 시스템은 소유자의 통계 기록을 위해 내부적으로 해당 링크의 클릭 횟수(Count)를 증가시킨**다**.

---

## 2. 소유자: 링크 추가/수정/삭제 등 전반 관리 과정

### 2.1 가입 및 로그인 (접근)
- 사용자(소유자)는 회원가입 시 번거로운 입력 폼 작성 시간을 아끼고 곧바로 서비스 관리를 시작하**기 위해** 첫 화면에서 구글 소셜 로그인 버튼을 클릭하여 인증**한다**.
- 사용자(소유자)는 자신만의 고유한 방문 URL 주소를 부여받**기 위해** 구글 소셜 로그인 가입 시 자동으로 연동되는 지메일 아이디 부분(`@` 앞부분)을 본인의 URL 식별자로 부여받는**다**.

### 2.2 프로필 관리 (인라인 편집)
- 사용자(소유자)는 대중에게 자신의 명칭이 어떻게 보일지 결정하**기 위해** 최상단의 디스플레이 네임 텍스트 영역을 클릭하여 인라인(Inline)으로 텍스트를 곧바로 수정**한다**.
- 사용자(소유자)는 방문자에게 본인을 텍스트로 짧게 소개하**기 위해** 디스플레이 네임 하단의 바이오(Bio) 영역을 더블클릭(혹은 클릭)하여 인라인으로 입력**한다**.
- 사용자(소유자)는 이렇게 수정한 인라인 텍스트 내용을 데이터베이스에 온전히 저장하**기 위해** 키보드의 엔터(Enter) 키를 누르거나, 수정 칸 바깥의 빈 화면 여백 공간을 클릭**한다**.

### 2.3 링크 관리 (추가)
- 사용자(소유자)는 공유하고 싶은 새로운 타겟 웹사이트 정보를 기재할 빈 공간 요소(블록)를 화면에 새로 만들기**위해** 리스트 하단의 '+ 새 링크 추가' 버튼을 클릭**한다**.
- 사용자(소유자)는 새롭게 만들어진 링크 블록이 유효한 목적지와 이름을 갖게 하**기 위해** 해당 블록 안의 미입력(Empty) URL 표시부와 제목 영역을 각각 클릭하여 인라인으로 타이핑**한다**.
- 사용자(소유자)는 입력된 URL 경로에 구글 파비콘 API가 잘 작동하는지 점검하**기 위해** 엔터를 쳐서 입력이 완료된 직후 아이콘 이미지가 올바르게 로드되는지 확인**한다**.

### 2.4 링크 관리 (수정)
- 사용자(소유자)는 이전에 이미 등록했던 특정 링크의 주소가 바뀌었거나 제목 오타를 수정하**기 위해** 대상 링크 리스트 위에서 텍스트를 클릭하여 즉시 인라인 편집**한다**.
- 사용자(소유자)는 링크 내용의 입력을 마친 후 변경 사항을 시스템에 최종 반영하**기 위해** 동일하게 엔터 키를 누르거나 다른 영역을 클릭**한다**.

### 2.5 링크 관리 (삭제)
- 사용자(소유자)는 만료된 홍보 이벤트나 더 이상 외부에 노출하고 싶지 않은 항목을 나의 페이지에서 완전히 지우**기 위해** 해당 링크 블록의 우측(내부)에 자리한 삭제(휴지통) 아이콘을 클릭**한다**.
- 사용자(소유자)는 클릭 실수로 인해 중요하게 등록해둔 링크 데이터를 영구적으로 날려버리는 사고를 방지하**기 위해**, 나타나는 '해당 링크를 정말 삭제할까요?' 모양의 경고 팝업(Alert) 모달창에서 '확인'을 클릭**한다**.

### 2.6 최종 반영 확인
- 사용자(소유자)는 작성 및 수정이 완료된 내용이 실제 외부 방문객들의 스마트폰이나 웹 브라우저에서 어떻게 보이는지 검증하**기 위해** 본인의 퍼블릭 URL(`/디스플레이네임`)을 새 창이나 탭에서 열어본**다**.
